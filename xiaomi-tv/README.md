# Xiaomi TV: прибрати PatchWall і рекламу

Скрипт `debloat.sh` вимикає (не видаляє) рекламні сервіси Xiaomi через ADB по Wi-Fi.
Список пакетів взято з [Kamikazi951/xiaomitv-debloat-toolkit](https://github.com/Kamikazi951/xiaomitv-debloat-toolkit) (MIT),
додано перевірки безпеки.

## Підготовка ТВ
1. Налаштування → Про пристрій → 7 разів натиснути «Збірка».
2. Параметри розробника → увімкнути «Налагодження USB» / «по мережі».
3. Встановити ADB на комп'ютер у тій самій Wi-Fi мережі.

## Запуск
```bash
./debloat.sh find               # знайти ТВ у мережі (потрібен nmap)
./debloat.sh plan 192.168.1.45  # що буде вимкнено — нічого не змінює
./debloat.sh apply 192.168.1.45 # вимкнути (спитає підтвердження)
./debloat.sh restore 192.168.1.45  # повернути все назад
```
`--keep-netflix` — не вимикати Netflix.

## Що робиться
- Завжди: Xiaomi TV+ / Mi Channels, вкладка «MI HOME», рекламні банери, телеметрія, демо-режим.
- Сам PatchWall і Google TV launcher — **лише якщо встановлено інший лаунчер** (напр. Projectivy Launcher),
  інакше ТВ залишився б без домашнього екрана.
- Ніколи не чіпає ефірний/супутниковий тюнер, HDMI, пульт, Bluetooth, Dolby, клавіатуру.
